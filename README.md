
# 🛎️ ELuwas Guest Information System (EGIS)              #


## 📌 Overview
ELuwas Guest Information System is a Java-based desktop application 
built to streamline the registration, tracking, and management of 
guest information for establishments such as hotels, inns, or 
community centers.

## 🛠️ Technologies Used
- Java (Swing for GUI)
- NetBeans IDE
- MySQL (Database)
- JDBC (Java Database Connectivity)

## ✨ Key Features
- Add and manage guest records
- Check-in/check-out tracking
- Search and filter guest entries
- Printable reports for records
- User login & access control
- Clean desktop GUI with data validation
